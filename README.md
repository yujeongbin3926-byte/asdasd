# 웹전시 GitHub Pages 업로드 파일

## 업로드 파일

이 폴더 안의 `index.html`, `sources.md`, `A01_bangasayusang.png`, `A02_yeonga.png`, `A03_pagoda.png`를 GitHub 저장소 루트에 업로드하세요. ZIP 파일 자체를 저장소에 올리면 웹사이트가 배포되지 않으니 압축을 먼저 푸세요.

## Pages 공개

1. 저장소의 `Settings` → `Pages`를 엽니다.
2. `Build and deployment`의 `Source`에서 `Deploy from a branch`를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 선택하고 저장합니다.
4. Pages 배포가 끝나면 `Settings` → `Pages`에 표시되는 주소를 엽니다.

사이트는 공개 URL로 게시됩니다. 사진 원본의 최초 다운로드 주소와 개별 이용 표시는 `sources.md`에 적힌 확인 메모를 참고하세요.
